# Amanuensis — versioni per Windows

Qui si trovano gli installatori di Amanuensis e il canale firmato da cui l'app scarica
gli aggiornamenti.

Per scaricare il programma vai su <https://amanuensis.up.railway.app>.

Ogni versione è firmata (Ed25519) e l'app verifica firma, SHA-256 e dimensione prima
di installarla.

Amanuensis è gratuito ma non open source: questo repository contiene solo i pacchetti
di installazione, non il codice.
